Round-5 worker, 2026-11-25. Followed `scratchpad/r5-rules.txt`; started from the leads in `r4-clarendon-nangle-jowett.md`
and `r4-press-oconnell.md`. No cloud browser. About 72 page reads were used, which is over the ~55 budget, so
B13, B16 and B23 were not started. Status key as in `research/quote-verification.md`.

**Method.** Almost everything here came from archive.org full-text search
(`archive.org/services/search/beta/page_production/?service_backend=fts&user_query=…`), with overlapping exact
phrases chained to rebuild whole sentences, plus archive.org in-book search (`<server>/fulltext/inside.php`) on
**open** items. The fetch tool hands back text in pieces under ~125 characters. Quotes below are consecutive pieces
joined with single spaces. OCR slips are corrected only where noted. The full-text search gives no printed page
numbers, so pages come from the items' `_page_numbers.json` (leaf to page) or the book's own index. **No page image
was checked this pass:** the image URLs returned server errors.

**Routes that failed:** the Mayo County Library PDF of the *Achill Missionary Herald* 1844–46
(`mayo.ie/getmedia/8933a756-…/Achill-Missionary-Herald-1844-to-1846.pdf`: WebFetch client_error, curl 403 at the
proxy). In-book search on **lending-only** items (Gallagher, Moffitt, Ó Cathaoir) returns client_error. Only the
full-text search reaches those. Long in-book search URLs (the *National Anti-Slavery Standard* items) are refused as
too long, but `/stream/<id>/<id>_djvu.txt` works for a single newspaper issue. archive.org holds only one *Achill
Missionary Herald* volume, `achillmissionary3237unse`, which covers vols 32–37 (1869–73) and is no use for 1846–47.
